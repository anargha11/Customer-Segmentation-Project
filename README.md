# Customer Segmentation Project

## Objective
Segment customers based on income and spending behavior using K-Means Clustering.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-Learn
- Google Colab

## Dataset
Mall Customers Dataset

## Methodology
1. Data Loading
2. Data Analysis
3. Elbow Method
4. K-Means Clustering
5. Visualization

## Results
Five customer segments were identified:
- Premium Customers
- Potential Customers
- Young Shoppers
- Budget Customers
- Regular Customers
